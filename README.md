
# EY SAP P2P ETL Studio

## Converted from Flask API to Streamlit

### Modules
- Overview Dashboard
- Connection Manager
- Schema Explorer
- Column Profiler
- Control Table
- Cast Rules
- ETL Execution
- ETL Logs

### Run

pip install -r requirements.txt

streamlit run app.py

### Architecture

SAP HANA --> Streamlit ETL --> SQL Server
